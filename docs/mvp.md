# CimeBook MVP

The first complete version of CimeBook should include only the essential features.

## Public Features

- View homepage
- View activity list
- View activity details
- View guide profile

## Client Features

- Register
- Login
- Book an activity
- View my bookings
- Cancel a booking

## Guide Features

- Create and edit guide profile
- Add an activity
- Manage activity availability
- View bookings for my activities

## Admin Features

- Manage users
- Manage activities
- Manage bookings

## Not Included in the First Version

- Real online payment
- Chat system
- Advanced map
- Mobile app
- Complex AI system
