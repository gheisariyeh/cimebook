# CimeBook - Project Idea

CimeBook is an online platform for booking mountain activities around Annecy, France.

It works like a small marketplace between tourists and local mountain guides.

## Main Users

### Tourist / Client

A tourist can search for activities, view details, choose a guide and make a booking.

### Guide

A guide can create a profile, publish activities and manage availability.

### Admin

An admin can manage users, activities and bookings.

## Example Activities

- Hiking around Semnoz
- Climbing in Talloires
- Canyoning near Angon
- Skiing in La Clusaz
- Via ferrata in the Aravis area
